# SettlersOfIdlestan
An idle management game where you lead a civilization to greatness.

Projects description:
- SettlersOfIdlestan: Model/Controller layers
- SettlersOfIdlestanSkia: hex map rendering (SkiaSharp) + game loop
- SettlersOfIdlestanUI: Avalonia overlay (controls, view models) shared by every head
- SettlersOfIdlestanAvalonia.Desktop: desktop head (Windows/Linux/macOS, Steam)
- SettlersOfIdlestanAvalonia.Browser: WebAssembly head
- SettlersOfIdlestanAvalonia.iOS: iOS head
- SOITests: tests for Model/Controller layers
- SOIUITests: tests for the Avalonia overlay
